# Visual QA screenshots

Store before/after captures here for customer-facing route changes. Use fixed viewport widths (**390**, **768**, **1440**) and the same browser zoom (100%).

Suggested filenames: `{route-slug}-{breakpoint}-{state}.png` (e.g. `home-390-default.png`, `merge-pdf-768-order.png`).

Regenerate after `npm run dev:fresh` if tool routes return 500 from stale `.next` vendor chunks.
